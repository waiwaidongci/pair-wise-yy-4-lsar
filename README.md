# 水下考古潜水记录

直接打开`index.html`使用。点击平面图添加标记，支持筛选、编辑、删除、时间线、冲突裁决和导出JSON。

## 离线合并

分队船与岸基整理室各自离线记录，回码头后通过「导入JSON」合并：

- **操作流水**：所有改动（潜次/标记的新增、修改、撤掉）都带设备号、基准版本和操作号（`设备号#序号`），导出包是操作流水而非整包覆盖。
- **幂等**：同一操作号重传只认首次结果，重复导入不会重复应用。
- **撤掉优先**：已撤掉的标记，迟到的编辑导入后直接跳过，不会重新出现。
- **字段级冲突挂起**：两边离线时改了同一字段，保留两份现场值并标记「挂起」，在「冲突处理」中选择采用本机值或对方值。
- **导入批次可恢复**：导入按批次落盘，每条操作应用后更新断点；崩溃后打开页面会提示「继续导入」，已应用的操作不会重复。
- **旧数据升级**：首次打开旧版数据时自动迁移，为每条记录补设备号、版本等来源信息，并记入迁移批次。
